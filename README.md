# «Маски сняты» — сайт клуба мафии в Смоленске

Сайт «Маски сняты» (ранее Fox Club), Смоленск: афиша и запись на игры, протоколы игр, рейтинг месяца по системе Федерации спортивной мафии (ФСМ), админка для ведущих и администраторов.

Всё работает на одном сервере: база PostgreSQL, приложение на Node.js и Caddy, который сам получает и продлевает HTTPS-сертификат. Сайт не обращается к сторонним серверам: шрифты и 3D-библиотеки раздаются с вашего домена. Это упрощает соблюдение 152-ФЗ.

## Запуск на VPS (примерно 20 минут)

### 1. Сервер и домен

1. Арендуйте VPS у российского провайдера (Timeweb Cloud, Selectel и т. п.):
   - Ubuntu 24.04;
   - 1 vCPU, 2 ГБ RAM, от 20 ГБ диска;
   - регион в России.
2. Купите домен (reg.ru, nic.ru) и в настройках DNS создайте две записи типа **A** с IP-адресом сервера:
   - `maski-snyaty.ru`;
   - `www.maski-snyaty.ru`.

   DNS обновляется от нескольких минут до нескольких часов.

### 2. Подготовка сервера

Подключитесь к серверу (`ssh root@IP-адрес`) и выполните:

```bash
# Docker
curl -fsSL https://get.docker.com | sh

# Файрвол: открыть только SSH и веб
ufw allow 22/tcp && ufw allow 80/tcp && ufw allow 443/tcp && ufw --force enable
```

### 3. Загрузка проекта

Скопируйте архив проекта на сервер со своего компьютера и распакуйте:

```bash
scp lupin.zip root@IP-адрес:/opt/
ssh root@IP-адрес
cd /opt && apt-get install -y unzip && unzip lupin.zip && cd lupin
```

### 4. Настройки

```bash
cp .env.example .env
openssl rand -hex 24      # скопируйте результат — это пароль базы
nano .env                 # заполните DOMAIN, ACME_EMAIL и POSTGRES_PASSWORD
```

### 5. Запуск

```bash
docker compose up -d --build
docker compose logs -f app     # должно появиться ««Маски сняты» слушает порт 3000», выход — Ctrl+C
```

### 6. Первый администратор

```bash
docker compose exec app node scripts/create-admin.js stepan "Степан"
```

Скрипт спросит пароль (от 10 символов). Затем откройте `https://ваш-домен/admin/` и войдите.

В админке:
- в разделе «Афиша» добавьте игры;
- в разделе «Сотрудники» создайте логины ведущим.

Если администратор забыл пароль, запустите ту же команду с тем же логином — пароль будет перезаписан.

## Показ на своём компьютере (без сервера и домена)

Чтобы показать сайт человеку в той же сети (офис, Wi-Fi дома), достаточно своего компьютера.

1. Установите **Docker Desktop** (Windows или macOS) и запустите его.
2. Распакуйте проект, откройте в его папке терминал (на Windows — PowerShell) и выполните:
   ```bash
   docker compose -f docker-compose.local.yml up -d --build
   docker compose -f docker-compose.local.yml exec app node scripts/create-admin.js admin "Администратор"
   ```
3. Откройте у себя `http://localhost:3000`, админка — `http://localhost:3000/admin/`.
4. Второму человеку дайте адрес вида `http://192.168.1.25:3000` — это IP вашего компьютера в сети
   (Windows: `ipconfig`, строка «IPv4-адрес»; macOS: Настройки → Сеть). Если не открывается — разрешите
   Docker в брандмауэре Windows для частной сети.

Пока компьютер включён и Docker запущен — сайт работает. Остановить: `docker compose -f docker-compose.local.yml down`
(данные сохранятся до следующего запуска). Этот режим только для показа: без HTTPS и резервных копий.

## Работа в админке

| Раздел | Кто видит | Что делает |
|---|---|---|
| Протокол | все | Внести игру: формат, дата, стол, ведущий, результат, роли, допы, ошибки, удаление, первый убитый и его лучший ход. Итог считается сразу, ошибки подсвечиваются до сохранения. |
| Игры | все | Протоколы за месяц. Ведущий правит только свои, администратор — любые и может удалять. |
| Афиша | администратор | Добавить, изменить или скрыть игру. Игру с заявками удалить нельзя — только скрыть. |
| Заявки | администратор | Заявки с сайта и их статусы. Отменённая заявка освобождает места. |
| Игроки | администратор | Переименовать игрока (история сохраняется), объединить дубли, удалить карточку без игр. |
| Галерея | администратор | Фото вечеров для раздела «Вечера клуба»: загрузить сразу несколько (браузер сам уменьшит их до 1600 px), подписать, указать дату, скрыть или удалить. Фото хранятся в базе и попадают в ежедневную копию. |
| Telegram | администратор | Уведомления о новых заявках в Telegram: подключить свой чат или группу, проверить связь, решить, показывать ли имя и контакт гостя. |
| Сотрудники | администратор | Ведущие и администраторы, сброс паролей, отключение доступа. |
| Журнал | администратор | Кто, что и когда менял. Удалённые протоколы сохраняются здесь целиком. |

Если в протоколе встречается ник, которого ещё нет в базе, админка попросит подтвердить создание нового игрока. Это защищает рейтинг от опечаток: «Доцент» и «Доцeнт» с латинской «e» — разные карточки.

## Уведомления о заявках в Telegram

Бот присылает сообщение о каждой новой заявке: на игру (вечер, число мест, сколько осталось), корпоратив, день рождения или рассылку. Ничего, кроме токена, настраивать не нужно: сервер сам опрашивает Telegram, отдельный адрес для бота не нужен.

1. В Telegram откройте **@BotFather**, отправьте `/newbot`, задайте имя (например, «Маски сняты — заявки») и адрес бота (должен заканчиваться на `bot`).
2. BotFather пришлёт токен вида `123456789:AA...`. Впишите его в `.env` на сервере: `TELEGRAM_BOT_TOKEN=123456789:AA...`
3. Перезапустите сайт: `docker compose up -d`
4. В админке откройте раздел **Telegram** → «Подключить Telegram» → откройте ссылку и нажмите «Старт». Через пару секунд чат появится в списке. Для общей группы — кнопка «Добавить в группу».

Подключать можно сколько угодно чатов: свой, ведущих, общую группу. Отключить — кнопкой в админке или командой `/stop` боту. Если бота заблокировали, сайт сам перестаёт туда писать.

**Личные данные.** По умолчанию в Telegram уходят только вечер и число мест — имя и телефон гость оставляет на сайте, а смотреть их нужно в админке. Серверы Telegram находятся за рубежом, поэтому отправка туда имени и контакта — трансграничная передача персональных данных: по 152-ФЗ о ней нужно уведомить Роскомнадзор. Галочка «показывать имя, контакт и комментарий гостя» в разделе Telegram включает полные уведомления — включайте её после того, как уведомление подано.

Уведомление уходит в фоне: если Telegram недоступен, заявка всё равно сохраняется, а сайт повторит попытку.

## Подсчёт очков (московская мафия, правила ФСМ)

| За что | Очки |
|---|---|
| Победа команды | +1 |
| Доп. баллы ведущего победителю | от +0,2 до +0,7 |
| Доп. баллы проигравшему | до +0,4 |
| Сумма допов за стол | не больше 1,2; при ничьей допы не даются |
| Лучший ход первого убитого (мирный или шериф): 2 / 3 чёрных | +0,25 / +0,5 |
| Компенсация первому убитому Ci | i × 0,4 / B, не больше 0,4 |
| Ошибка, повредившая команде | −0,4 |
| Удаление / удаление с ППК | −0,5 / −1 |

В формуле Ci:
- **i** — сколько раз за месяц игрока убивали первым, когда он был мирным или шерифом;
- **B** — 40% от числа его игр за месяц (с округлением).

Если красные проиграли, первый убитый получает Ci полностью. Если красные выиграли и в его лучшем ходе есть хотя бы один чёрный — половину.

В питерской мафии считаются победа, допы и штрафы.

**Рейтинг месяца:**
- допуск — от 6 игр;
- места по сумме очков, при равенстве — по среднему баллу;
- первые 10 играют финал.

Константы задаются в начале файла `shared/scoring.js`.

Правила проверяются в трёх местах:
- в браузере — подсказки во время заполнения;
- на сервере — тот же модуль `shared/scoring.js`;
- в самой базе — триггер `validate_game`, поэтому неверный протокол нельзя записать даже в обход сайта.

## Резервные копии

- Копия базы делается раз в сутки и лежит в папке `backups/` рядом с проектом. Хранятся последние 14 дней.
- Регулярно скачивайте копии к себе: если сервер сломается целиком, папка пропадёт вместе с ним.

  ```bash
  scp root@IP-адрес:/opt/lupin/backups/*.dump ./
  ```

- Восстановление из копии:

  ```bash
  docker compose exec -T db pg_restore -U lupin -d lupin --clean --if-exists < backups/lupin_2026-10-07_0300.dump
  docker compose restart app
  ```

## Обновление сайта

Загрузите новую версию поверх старой (файл `.env` и папку `backups/` не трогайте) и выполните:

```bash
docker compose up -d --build
```

Изменения базы (миграции из `db/migrations/`) применяются автоматически при старте.

## Полезные команды

```bash
docker compose ps                    # что запущено

docker compose logs backup           # журнал резервного копирования
```

## 152-ФЗ: что сделать владельцу

- [ ] Заполнить шаблон `public/privacy.html` (реквизиты, e-mail) и показать юристу.
- [ ] Подать уведомление об обработке персональных данных в Роскомнадзор (pd.rkn.gov.ru).
- [ ] Использовать сервер, расположенный в России.
- [ ] Если в Telegram-уведомлениях нужны имя и контакт гостя — указать трансграничную передачу в уведомлении Роскомнадзору и в политике конфиденциальности, и только потом включить галочку в админке.

Что уже есть в проекте:
- согласие в форме записи;
- автоматическое обезличивание заявок через 365 дней (`BOOKING_RETENTION_DAYS`);
- никаких сторонних счётчиков и CDN;
- Telegram-уведомления по умолчанию без имени и контакта гостя.

## Для разработчика

```
server/          приложение (node:http, без фреймворков)
  routes/        public.js — афиша, запись, рейтинг; staff.js — вход, протоколы; admin.js — управление
  db.js          подключение к PostgreSQL (драйвер pg)
  minipg.js      запасной клиент PostgreSQL для разработки без npm install
  migrate.js     применение миграций
shared/
  scoring.js     подсчёт очков ФСМ — общий для сервера и браузера
db/migrations/   схема базы с проверками протоколов
public/          сайт (index.html, js/site.js, css/site.css) и админка (admin/)
scripts/         create-admin.js, check-vendor.js
test/            юнит-тесты подсчёта и интеграционные тесты API
deploy/          Caddyfile и скрипт резервного копирования
```

### Локальный запуск

Нужны Node.js 20+ и PostgreSQL 14+.

```bash
npm install
export DATABASE_URL=postgres://user:pass@localhost:5432/lupin
node scripts/create-admin.js admin "Админ"
npm start          # http://localhost:3000
```

### Тесты

Используйте **отдельную** базу: тесты её полностью очищают.

```bash
TEST_DATABASE_URL=postgres://user:pass@localhost:5432/lupin_test npm test
```

### Безопасность

- Пароли хранятся как хеши scrypt.
- Сессии хранятся в базе, в cookie лежит только случайный токен: HttpOnly, Secure, SameSite=Strict.
- Каждый изменяющий запрос проверяется на заголовок `X-Requested-With` и Origin.
- Действует ограничение частоты попыток входа и отправки заявок.
- Строгий CSP без внешних источников.
- Все SQL-запросы параметризованы.
